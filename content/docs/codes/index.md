Some characters can still be found on **The Lodestone** with **Echo** codes on
their bios. It can be confusing so here's a little breakdown of them:

## Claim codes

`echo-claim-[0-9a-f]{8}|[0-9A-Z]{10}`

* Old format: **echo-claim-deadbeef**
* New format: **AZBYCXDW10**

This code is for the "Claim your character" feature of **EchoVault**.
We don't recommend to use this as it sends data to them.

Characters with this code *could* be plugin users, but most of them just wants
control over their own characters on the site.

## Takedown codes

`echo-takedown-[0-9a-f]{8}|[0-9A-Z]{10}`

* Old format: **echo-takedown-deadbeef**
* New format: **AZBYCXDW10**

This code is for the "Character removal" form of **EchoVault**.
We don't recommend to use this as it sends data to them.
(has also shared those forms on his Discord to make fun of it in the past).

Again, characters with this code *could* be plugin users hiding themselves from
the site, but most of them just wants to be removed for privacy reasons.

## User verification codes

`ECHO-[0-9A-F]{8}|[0-9A-Z]{10}`

* Old format: **ECHO-DEADBEEF**
* New format: **AZBYCXDW10**

There's only one use for this code: becoming a verified user to contribute
sightings on **EchoVault** as a stalker. The old format was uniquely
identifiable but the new format is now shared with claim/takedown codes so new
stalkers can't be identified with this alone.

![Discord announcement 2026-09-18](discord-2026-09-18.png)

> The auditing method for characters on the [**Sunnie Sunday Report**](/) used
> API exploits directly and didn't rely on **Lodestone** code. That said, adding
> that code was the process that those leaked characters had completed.
