Some characters can currently be found on the Lodestone with Echo codes in their
bios. This can lead to some confusion so here's a little breakdown of them:

## Claim codes

* Format: `echo-claim-deadbeef`

This code is for the "Claim your character" feature of EchoVault.
We do not recommend to use this as it sends data to EchoVault's developper.

Characters with this code *could* be users, but most of them just wants control
over their own characters on the site.

## Takedown codes

* Format: `echo-takedown-deadbeef`

This code is for the "Character removal" form of EchoVault.
We do not recommend to use this as it sends data to EchoVault's developper.
(has also shared those forms on his Discord to make fun of it in the past).

Again, characters with this code *could* be users hiding themselves on the site,
but most of them just wants to be removed for privacy reasons.

## User verification codes

* Old format: `ECHO-DEADBEEF`
* New format: `DEADBEEF11`

There's only one use for this code: becoming a verified user to contribute
sightings on **EchoVault**. This is the process that the leaked characters on
the [**Sunnie Sunday Report**](/) have completed.
