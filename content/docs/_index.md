The **Sunnie Sunday Report** (`echo-unvaulted.net`) is a weekly report of discovered **EchoVault** contributors.
These characters were found with our own tools exploiting a few security oversights in **Echo**'s protocol.

The report is to let stalkers know they aren't anonymous and can be caught by playing their own game.
Good news: so far this plugin isn't as popular as it's developer would like it to be.
